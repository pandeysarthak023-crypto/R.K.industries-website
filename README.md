# RK Industries Website

Professional website for RK Industries - Premium Packaged Drinking Water Manufacturing Unit in Moradabad, Uttar Pradesh.

## 🌟 Features

- **Responsive Design**: Fully responsive website optimized for mobile, tablet, and desktop
- **Modern UI**: Built with Tailwind CSS for clean, professional appearance
- **FSSAI Certified**: Highlights certifications and quality assurance
- **WhatsApp Integration**: Direct WhatsApp contact for inquiries
- **Service Showcase**: Display of bulk supply services and products
- **Facility Information**: Location and facility details

## 📋 Services

- **Packaged Bottles**: Manufacturing 250ml, 500ml, and 1 Litre bottles
- **Event Wholesale**: Direct plant supply for events and gatherings
- **Retail Distribution**: Wholesale supply for retail outlets and supermarkets
